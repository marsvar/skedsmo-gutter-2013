# Øvelsesdatabase — NFF Spillmodell

Referansedokument for trenere på 2013-laget. Alle øvelser er hentet fra [tiim.no](https://tiim.no) og organisert etter NFF Spillmodell-kategoriene.

**Aldersfokus:** 12–13 år (overgang 9v9 → 11v11)

---

## NFF Spillmodell — oversikt

| Kode | Fase | Tema |
|------|------|------|
| A1 | Angrep | Behandle/vinne ballen og spille fremover — *Bearbeiding* |
| A2 | Angrep | Komme til prioritert rom — *Inn i prioriterte rom* |
| A3 | Angrep | Avgjøre/score mål — *Komme til avslutning* |
| F1 | Forsvar | Presse, lede og kontrollere — *Presse – Lede – Styre* |
| F2 | Forsvar | Sperre prioritert rom — *Hindre tilgang på prioriterte rom* |
| F3 | Forsvar | Hindre avslutning og mål — *Hindre avslutning – hindre mål* |

### NFF Øktstruktur (Landslagsskolen)

| Del | Andel | Innhold |
|-----|-------|---------|
| Prepp | 25 % | Oppvarming — «Sjef over ballen». Aktivering, frekvens, kroppskontroll |
| Situasjonsøvelse | 25 % | Spille med og mot — mange kamplike repetisjoner på temaet |
| Kamptilpasset spill | 50 % | Spill mot ett eller to mål med regler/organisering som fremhever temaet |
